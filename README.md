# Creative Scrapbook Portfolio

An interactive doodle scrapbook portfolio featuring hand-drawn visuals, sound effects, interactive stamps, and creative design work.

## ✨ Features
- **Scrapbook Aesthetic**: Textured paper, washi tape effects, hand-drawn stickers, and stamps.
- **Interactive Stamp Mode**: Stamp anywhere on the screen with playful doodles and sound effects.
- **Work Showcase**: Highlights Branding, Motion Design, Editorial Posters, and Merch Illustration.
- **Fast & Responsive**: Pure HTML5, CSS3, and Vanilla JavaScript with zero heavy build steps.

## 🚀 Deployment on Vercel
1. Go to [Vercel](https://vercel.com).
2. Click **"Add New..."** -> **"Project"**.
3. Import your GitHub repository: `aditikhandelwal412-cpu/Portfolio`.
4. Keep the default settings (Framework Preset: **Other**) and click **Deploy**.
5. Every time you push changes to GitHub (`git push`), Vercel will automatically re-deploy your site!

## 💻 Local Preview
You can run the included PowerShell server:
```powershell
./server.ps1
```
And navigate to `http://localhost:8080/`.
